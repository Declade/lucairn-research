# Consumer-finance terms safelist for Paper 2 — the Lucairn Research Program's
# CFPB Consumer Complaint Database / GLBA NPI benchmark.
#
# Loaded by the sanitizer at startup as a lowercase set; consulted in
# `_drop_tech_term_overlaps`-style logic to suppress PERSON / LOCATION / ID
# false-positives that fire on consumer-finance prose.
#
# Scope: this list is INTENTIONALLY narrow to consumer-finance vocabulary. It
# does NOT touch SECRET / EMAIL / PHONE / IBAN / CC / DOB / URL spans (those
# classes do not have the FP problem and a stray term that overlaps a real
# credential must NEVER be dropped). Match is exact, lowercased, whole-span
# (the "any word in span" check in `presidio_scan.py:357-364` means one
# safelisted word makes the entire span safe).
#
# Sources of FPs targeted by this list (Paper 2 baseline-run analysis):
#   - Bank brand names misread as PERSON (Wells Fargo, Chase, JPMorgan…)
#   - Card-network names misread as PERSON or ORG (Visa, MasterCard…)
#   - Common consumer-finance terms misread as PERSON or LOCATION (Discover, Capital, …)
#   - Common finance abbreviations misread as PERSON or ID (FICO, APR, …)
#
# Cite-back:
#   - Sanitizer integration: dual-sandbox-architecture/services/sanitizer/presidio_scan.py:343-365
#   - Paper 1 equivalent: ../../paper-1-healthcare/sanitizer-config/medical-terms.txt (file on the box)
#
# Multi-character only. Short tokens like "IRA" (3 chars but ambiguous with
# names), "ACH" (could be a name), "APR" (April abbreviation collision) are
# excluded — they would over-match.
