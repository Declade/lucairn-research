# Consumer-finance terms safelist for Paper 2 — the Lucairn Research Program's
# CFPB Consumer Complaint Database / GLBA NPI benchmark.
#
# Loaded by the sanitizer at startup as a lowercase set; consulted by the
# `safe_terms_file` mechanism in `presidio_scan.py:154-365` to suppress
# PERSON / LOCATION / ID false-positives that fire on consumer-finance prose.
#
# Scope discipline (Paper 1's hard-learned lesson — see clinical-pii blog
# Intervention 1): the safe-terms match is "any word in span", which means a
# single common-English entry in the safelist makes EVERY span containing it
# safe. We DO NOT include generic English nouns/verbs like "credit", "balance",
# "mortgage", "deposit" — they have legitimate non-PII meanings but could
# also appear inside a real PII span ("John Mortgage" tagged PERSON would be
# dropped if "mortgage" were safelisted, even if "Mortgage" is a real surname).
#
# What we KEEP:
#   1. Multi-word bank / brand / card-network names (low ambiguity)
#   2. Distinct finance abbreviations + acronyms with no common-English collisions
#   3. Credit-bureau names + US-finance regulator names
#   4. Specific multi-word finance vocabulary (e.g. "fannie mae", "freddie mac")
#
# What we DROP (vs the initial draft, after the Paper 1 broadness audit):
#   - Single-word nouns like credit, debit, deposit, balance, mortgage, escrow
#   - Common adjectives like delinquent, foreign, annual
#   - Generic finance verbs (refinance, refinanced)
#
# Sources of FPs targeted by this list (predicted from baseline-run analysis):
#   - US bank brand names misread as PERSON (Wells Fargo, Chase, JPMorgan, …)
#   - Card-network names misread as PERSON or ORG (Visa, MasterCard, …)
#   - Loan-program acronyms misread as ID (FHA, VA, USDA loan)
#
# Cite-back:
#   - Sanitizer integration: dual-sandbox-architecture/services/sanitizer/presidio_scan.py:343-365
#   - Paper 1 lesson: lucairn.eu/blog/clinical-pii-redaction-benchmark §Intervention 1
#   - GLBA Privacy Rule: 16 CFR Part 313 (regulatory backdrop for NPI enumeration)
