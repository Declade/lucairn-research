Domain-tuning methodology

A repeatable 8-phase process that produces empirical before/after PII-redaction benchmarks for any customer vertical. Healthcare (Paper 1) is the first instance; finance, legal, government, HR, education follow the same template. Time budget per vertical: ~2 weeks calendar, ~5 engineering-days, ~15 h pipeline wall-clock.

The 8 phases

0
Vertical scoping
1-2 h
5/5 go/no-go checks: real customer pain, regulator + taxonomy exists, public corpus exists, framable use case, named publication target.
1
Corpus acquisition
1-3 d
Fallback ladder: CC0 → CC-BY → DUA → customer-private → synthetic. Quality bar: ≥500 docs, ≥10 PII / doc.
2
Taxonomy mapping
1 d
Convert regulator's category schema into Lucairn annotation_types. Every category cites primary law.
3
Ground-truth build
1 d
Synthetic PII injection + 20-30 human-annotated rows for κ ≥ 0.85 sanity check.
4
Baseline run
~7 h
"Before" measurement with default sanitizer config. Same harness as every other paper.
5
Gap analysis
0.5 d
Top-50 FPs (safelist candidates) + per-category recall (recognizer / L3 prompt candidates).
6
Tuning interventions
0.5-1 d
Apply all three intervention types in one deploy.
7
After run + publish
~7 h + 2 d
Re-measure with tuned config (no other changes). Ship 5-artifact bundle.

Three intervention types (Phase 6)

Type 1 · Highest ROI

Domain vocabulary safelist

  • Top 50 recurring FP texts from Phase 5
  • Public domain vocabulary list (RxNorm, FASB, statute citations, agency abbreviations, …)
  • Wire as presidio.safe_terms_file — config only, no code change
Precision impact: +20-40 pp · Effort: 2-3 h
Type 2 · Targeted recall

Custom regex recognizers

  • One per weak HIPAA-equivalent category (Phase 5.b)
  • Pattern + relaxed-pattern + context-word list
  • Standard PatternRecognizer template — ~30 min each
Category recall impact: +30-70 pp · Effort: 3-5 h
Type 3 · Residual closure

L3 LLM prompt enumeration

  • Add category-specific examples to Qwen prompt
  • Include regulator citation for grounding
  • Closes the catch-all "other identifier" gaps
Overall recall impact: +5-10 pp · Effort: ~1 h

The narrative arc (constant across every paper)

Out-of-the-box {generic_tool} on {domain} data hits {RECALL_BEFORE}% recall and {PRECISION_BEFORE}% precision on {N} regulator-tagged entities. Here's why it fails — and what we did to fix it: [SPECIFIC INTERVENTIONS]. After tuning: {RECALL_AFTER}% recall and {PRECISION_AFTER}% precision, in {ENGINEERING_HOURS} hours of engineering. The dual-sandbox isolation invariant held at 100% throughout.
Only the nouns change between papers. By Paper 3, "Lucairn benchmark" is a recognizable brand asset.

What this process explicitly is NOT

NotA sales document. Numbers go where the data takes them. If precision tunes to 70% not 90%, that's the published number. The credibility moat depends on honest reporting.
NotA vendor-comparison framework. We compare our tuned config vs our untuned config, on the same dataset. Cross-vendor comparisons are a separate paper category.
NotA regulator-endorsed audit. Always frame as "we measured X" — never "we certify X".
